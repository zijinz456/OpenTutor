## Top 3 Features to Highlight in Marketing This Week

### 1. LLM-Graded Coding Questions (Week 31 post ready — submit now)

Week 31 (Aug 2) write-up covers the coding question type shipped in commit `90a0676`: LLM-based grading without code execution. The grading service sends question + reference answer + student code to the model; receives `is_correct` (bool) + 30-word feedback. The design decision — deliberate rejection of sandbox execution in favor of semantic equivalence checking — is fully written up as a Twitter thread (5 tweets), a Reddit/r/LocalLLaMA post, and the associated engineering rationale. The key differentiator: accepts any functionally equivalent implementation, not just the reference solution. **This post is ready to distribute; the Reddit post is drafted and strong.**

### 2. Zero-Overhead 3-Tier LLM Routing (Show HN draft ready — strongest post in the queue)

The Aug 4 community post draft includes a full Show HN write-up on the heuristic complexity scorer in `services/llm/complexity.py` (196 lines). The hook is unusually strong: a routing system that makes zero LLM calls. Four education-domain signals (message length, classified intent, active scene, conversation depth) plus regex complexity markers route each request to fast/standard/frontier tier in ~200µs. In practice: greetings and layout changes go to llama3.2:3b; study plan generation and multi-step curriculum planning go to the frontier tier. `resolve_tier()` floors planning agents at frontier regardless of score. **This is the most technically differentiated feature write-up in the queue — the "zero-cost routing" angle has strong HN appeal. Submit this week.**

### 3. Circuit Breaker for Local LLM Resilience (r/LocalLLaMA draft ready)

The Aug 4 community post batch includes a practical r/LocalLLaMA write-up on `services/llm/circuit_breaker.py` (83 lines): progressive cooldown steps (5s → 10s → 20s → 60s), auto-open after 3 consecutive failures, 120s auto-reset, 30s background health probe. The post explains the fallback chain (Ollama → DeepSeek → mock) in concrete terms with setup code. This is actionable content for r/LocalLLaMA's audience who run Ollama locally and deal with model crashes. **Scheduled for r/LocalLLaMA as follow-on to the routing post — submit after Show HN lands.**
